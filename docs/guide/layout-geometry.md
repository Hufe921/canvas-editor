# T10：提取旧循环中的布局职责

对象和表格几何现在位于 `src/editor/core/layout`，不引用 Draw、TextParticle、
BrowserTextShaper、Canvas、旧循环游标或 forceLegacy。调用者显式提供容器尺寸、
缩放、样式和单元格子布局回调；旧入口暂时调用这些模块，后续原生布局也可直接调用。

## 模块与边界

| 模块 | 已提取的职责 | 输入和结果 |
| --- | --- | --- |
| TableGeometry | 行列/合并格坐标、RTL 镜像、列宽收缩、最小高度、内容撑高、按合并终止行缩减空余高度 | table、scale、padding、maxWidth、minColumnWidth、mirrored、layoutCell 回调；返回表格度量 |
| InlineObjectMeasure | 图片/公式宽高和等比适配、题注高度、浮动图零行内度量、checkbox/radio gap | 原始尺寸、可用宽度、缩放、题注/控件尺寸；返回 metrics 和可选 adaptedSize |
| BlockMeasure | Block 宽度限制、分隔线、分页标记度量 | 显式尺寸、容器宽度、缩放、行边距；返回 metrics |
| ParagraphStyleResolver | 字号对应行边距、行盒、列表缩进、段前后距、Area 首次进入偏移和全隐藏行折叠 | 元素、相邻元素及样式/隐藏判定；返回几何或折叠决策 |
| FlowConstraints | 行/列可用宽度、结构强制换行、显式分页、翻栏/翻页选择 | 当前边界和容器约束；返回 stay/column/page，不持有排版状态 |

`TableParticle` 的既有行列/尺寸方法改为委托 TableGeometry，绘制、边框、选区和片段查询
继续留在 Particle。Draw 不再包含表格内容测量、合并格高度调节及图片/Block 度量算法。
表格算法按最小高度初始化、子布局、跨行末行扩展、内容高度记录、空余高度收缩和坐标刷新
拆分，未复制一份文字排版循环。

## 单位、回调和模型写入

- 表格、列宽、单元格 padding 采用未缩放模型单位；传入子布局的 innerWidth 和
  返回子行高度为缩放后的像素。表格测量将子行总高除以 scale 后再加 padding。
- rowspan 内容撑高落在跨度的最后一行；缩减使用按合并终止行分组的快照，
  防止调整前面的行时改变后续缩减依据。最终重新计算合并格与镜像坐标。
- 子布局回调收到 elements、innerWidth、direction、align 和 scope。
  它可以执行 HB 排版、递归调用几何模块或提供测试行高，不依赖旧文字循环。
- 图片测量不修改传入尺寸，返回 adaptedSize，由宿主提交原有 width/height 回写。
  表格仍按原有约定更新表格/单元格几何和 rowList；原生布局输出及文档/布局分离
  留在 T11/T12/T19。回调的 IRow 是当前显式过渡接口。
- 当前 Draw 的表格 maxWidth 仍显式传入原正文宽度，保持既有兼容策略；
  新模块支持任意容器，独立测试验证了嵌套容器。T12 再统一实际嵌套 td 宽度策略。
- 分页/分栏的游标、纸张方向切换、环绕碰撞与跨页表格片段仍由宿主管理。
  T10 提取几何规则，不提前完成 T12/T13/T15，也不声明 forceLegacy/旧循环已删除。

## 验证中修复的两处边界

1. 无可用字体时，空白/默认忽略字符的占位没有墨迹，却被新轮廓绘制当作缺失后端。
   shaper 现在显式输出 inkless 标记，renderer 跳过这些占位；可见缺字仍走诊断和 .notdef/盒。
   测试同时覆盖空页眉、Area 单元格和无字体空白，不恢复任何浏览器文字绘制回退。
2. legacy 显式分页原来依赖宽度溢出才能让分页符独立成行。
   Canvas mock 的零宽换行符有非零测宽，掩盖了浏览器中合并成一页的问题。
   FlowConstraints 现在对 PAGE_BREAK 明确强制换行，真实浏览器的竖/横/竖样本正确导出三页。
   这是有意修复的边界行为，未通过放宽页面数量断言处理。

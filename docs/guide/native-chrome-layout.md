# T14 原生控件、列表与装饰

控件、标签和列表的文字统一交给 HarfBuzz。几何在换行前确定，宿主仅投影到现有
绘制与交互入口，后续 T17/T19 继续迁移这些消费者。

## 控件与标签

- `ControlLayout` 使用 HB 的实际宽度计算 `minWidth` 差额，生成临时 `controlSpace`
  内联对象。补白有真实源元素锚点，不创建或修改持久化内容。长补白可跨行；
  VALUE_START 的续行缩进参与可用行宽计算，CENTER/RIGHT 在控件内分配补白。
- 移除 `applyEngineRowsMinWidth`、`applyEngineRowsMetrics` 和 Draw 中的续行平移。
  原生节点、字形、光标和兼容行共享相同几何。重复源元素跨行时使用独立投影，
  避免后行覆盖前行的补白盒。
- 标签保留原文字形簇和阿拉伯文连写。原生标签盒包含四边 padding，整块参与换行，
  行高预留 padding；背景盒不包含段落 rowMargin。
- 空行仍属于原生渲染入口；隐藏控件折叠宽高，不分配可见补白。
- normalizer 与序列化过滤历史 `isControlMinWidthPlaceholder`，语义 PLACEHOLDER
  仍正常保留，用于空值展示、赋值与缺字定位。

## 列表与装饰

- `collectListMarkers` 按 listId 延续序号，listWrap 不增加编号，嵌套列表保留独立身份。
  标记按实际字体、字重、样式和真实编号测量，避免多位编号宽度不足与重复缩放。
- 列表标记用 HB 字形轮廓绘制，不调用 Canvas `measureText` 或 `fillText`。
  原生 `TextLine.marker` 保存源锚点与标记几何，列表 gutter 与层级缩进进入段落宽度；
  RTL 嵌套标记不再重复扣除层级缩进而覆盖内容。
- Hyperlink/Date/控件 chrome 使用正文原生字形。标签背景、控件背景与边框、
  高亮、下划线、删除线和留痕使用投影几何；原生删除线、留痕不测量旧基准文字。
  编辑、复选框标签切换与只读规则沿用现有命令和事件逻辑。

## 缺字定位

覆盖扫描包含实际控件值、占位文字与生成的列表标记，不扫描排版补白。
页面详情提供“定位缺字”按钮。按源 nodeId 重新查找当前元素，设置正文/页眉/页脚
及嵌套表格路径，再选择源元素；已删除的源不会根据过期下标误选其他内容。
缺字盒也使用实际元素源标识，保持与覆盖报告一致。
